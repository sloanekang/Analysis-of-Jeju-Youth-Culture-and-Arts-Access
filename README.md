# Analysis of Jeju Youth Culture and Arts Access

**제주 청년 문화예술 접근성 분석**

하루온팀 기획안의 현황분석 결과를 보여 주는 대시보드입니다. 제주에 사는 만 19~34세 청년에게 공연·전시가 주말 여가의 선택지가 되고 있는지, 그리고 제주의 문화예술 공급과 청년의 관람·희망이 어떻게 이어지는지 살펴봅니다.

**대시보드 보기:** https://sloanekang.github.io/Analysis-of-Jeju-Youth-Culture-and-Arts-Access/

## 화면 구성

| 탭 | 내용 |
| --- | --- |
| 개요 | 이번 분석의 결론, 최종 문제정의문, 네 가지 관점(불편·갈등·결핍·가능성), 주요 지표 |
| 수요 ① 여가 속 위치 | 제주 청년의 주말 여가에서 문화예술이 차지하는 위치 |
| 수요 ② 관람과 희망 | 최근 관람한 분야, 앞으로 보고 싶은 분야, 관람을 막는 요인 |
| 공급 ① 전국과 비교 | 인구 대비 문화시설·활동·공연 판매를 전국과 비교 |
| 공급 ② 공연·전시 구성 | 2025년 제주 공연·전시의 시기, 장소, 대상, 운영 기간 |
| 주말의 선택지 | 주말마다 볼 수 있었던 공연 수와 공연이 없던 주말 |
| 청년문화예술패스 | 시도별 발급률·집행률과 제주의 추이 |
| 장르별 연결 | 장르별 공급과 청년의 관람·희망 비교 |
| 분석 결과 | 결론 카드와 현재 필터 기준 요약 |
| 데이터 기준 | 자료별 출처·기간·대상, 항목별 연령 기준, 이 자료로 말할 수 없는 것 |

그래프 위에 마우스를 올리면 값의 뜻, 계산식, 비교수(분자)와 기준수(분모)가 보입니다.

## 주요 자료

- 제주특별자치도 청년통계(2019·2022·2025)
- 『2025년 제주문화지표 조사연구 보고서』 도민 인식조사
- 국민문화예술활동조사, 국민여가활동조사, 통계청 사회조사(KOSIS)
- KOPIS 공연예술통합전산망 공연 목록·지역별 통계·예매상황판
- 제주문예회관·서귀포예술의전당·제주돌문화공원·국립제주박물관 공연·전시 일정
- 문화체육관광부 지역축제 개최계획
- 청년문화예술패스 관련 보도와 정책 브리프
- 주민등록인구(KOSIS)

자료별 기간, 대상, 주의할 점은 대시보드의 '데이터 기준' 탭에 정리했습니다. 19~34세 값은 공표 자료에 없는 구간이라 연령별 값을 가중 평균해 계산했습니다.

KOSIS 값은 내려받기 파일과 KOSIS 시범서비스 조회를 함께 사용했습니다. 분석·해석은 국가데이터처의 공식 입장이 아닌 참고용입니다.
